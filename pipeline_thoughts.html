Full Vision vs. CA3 Scope

Teacher's Pet is the scoped CA3 instance of a generalisable model: a personal knowledge concierge that indexes a professional's private library against their domain's reference frameworks and fills gaps intelligently.

Seven Numbered Decisions

Decision 1: Deep-parse all in-scope PDFs

Full deep parse of all ~3,300 PDFs is trivially cheap (~$6–16, ~90 min). There is no meaningful time or money saving from sampling. The catalogue is the product; it deserves honest tagging. Text-rich files → pdfplumber + DeepSeek classification. Image-heavy files → Gemini Flash vision (1 page per file for subject/format/grade; text extraction covers the rest).

→ Decision: Parse all PDFs in-scope. ~$6–16, ~90 minutes. Run overnight for image-heavy batch.

Decision 2: English + Maths only. Trim catalogue to match.

Language + Maths covers both Irish curriculum taxonomy styles (coded TF outcomes vs. progression continua). Adding more subjects is rote transcription. Trim catalogue to files whose primary subject is English or Maths (~1,800–2,200 files). Cross-curricular seasonal folders (xmas, halloween, back-to-school) stay in if content is literacy/numeracy.

→ Decision: Reference taxonomies for Primary Language (TF codes) + Primary Maths (PC continua). Catalogue trimmed to ~1,800–2,200 English/Maths files.

Decision 3: No Gaeilge

LLMs are materially weaker in Irish. Generating Irish-language educational content is an active research problem, not a CA3 deliverable. ~119 Gaeilge files tagged from folder only, excluded from demo queries. Named as deliberate exclusion with specific reasoning in the writeup — demonstrates AI-limitation awareness.

→ Decision: Exclude Gaeilge from catalogue, parsing, generation, and demo.

Decision 4: UFLI programme reference

UFLI Foundations (University of Florida Literacy Institute) is a structured phonics programme with 128 lessons in a fixed scope-and-sequence: Lesson 1 starts with short 'a' CVC words, through to affixes and advanced word study by Lesson 128. 24 files in the collection are already UFLI-tagged by filename. Authoring the scope-and-sequence as JSON lets the system answer "UFLI Lesson 54" queries, cross-reference to curriculum outcomes, and prevent generated plans from using untaught sounds. This is a separate reference layer from curriculum outcomes — a resource can be tagged with both.

→ Decision: Author full 128-lesson UFLI scope-and-sequence as JSON. Numicon and morphology taxonomies as skeletons only.

Decision 5: Search first, generate as fallback

Gap resolution: (1) query catalogue → (2) if gap, search curriculumonline.ie for public NCCA resources → (3) teacher reviews suggested resources, adds to catalogue → (4) only if nothing found and teacher requests: Maker generates a lesson plan. Generated content is marked with AI provenance. Teacher keeps control of what enters their catalogue.

→ Decision: Search-first, generate-as-fallback. Bundle = matched resources + teacher-approved discovered resources + generated lesson plan (only if gaps remain). No worksheet generation.

Decision 6: App-only Graph auth for demo

No user login. Cloudflare Worker uses Azure AD app-only credentials (client credentials flow) to access OneDrive. Zero friction for the demo. Content exposure through the Worker is acceptable for a graded project. Limitations section names delegated OAuth (MSAL.js) as the production fix with GDPR rationale.

→ Decision: Ship with app-only auth. No login. Document delegated auth as production path.

Decision 7: Parse all (see Decision 1)

→ Decision: See Decision 1.

Catalogue persistence — append, never rebuild

FilePurposeUpdate model
Catalogue.xlsxLive operational catalogue. Agents read/write at run time via Graph API. 18 columns.Append-only. New content → new row. Existing rows updated only by human disagreement flags.
Catalogue_raw.jsonImmutable archive of raw parse results (extracted text, Gemini tags, DeepSeek tags, confidence, timestamps).Write-once per file. Never modified. If tagging improves, re-parse and compare — never overwrite.

The parse pipeline is idempotent by file path: before parsing, check Catalogue.xlsx for an existing row with that OneDrive path. Found → skip. Not found → parse → append. Adding 50 new files next month runs the same script, skips 1,800 existing rows, parses 50 new ones. No rebuild.

Reference Taxonomies — Tying Resources to Outcomes

Resources get tagged not just by what they are but by what curriculum outcome they serve. This unlocks the two capabilities the brief requires: outcome-to-resource mapping, and gap detection.

Two regimes, one system

RegimeSubjectsOutcome formatCA3 scope
New framework (with codes) Primary Language (2019), Primary Maths (2023) TF codes (Language), Progression Continua PC1–PC12 (Maths) Full outcome mapping
1999 curriculum (prose only) SESE, SPHE, PE, Arts No outcome codes. Strand/unit prose per class band. Skeleton only (synthetic strand/stage codes, no outcome matching)

Example: Language Curriculum TF codes

Strand: Reading → Element: Understanding → Outcome 7: Purpose, genre, and voice
Stage 1 (Infants): "show understanding through body language, facial expression..."
Stage 2 (1st–2nd): "identify the purpose, genre, and voice of a text..."
Stage 3 (3rd–4th): "compare and contrast the purpose, genre, and voice..."
Stage 4 (5th–6th): "evaluate how purpose, genre, and voice shape meaning..."
→ Code: TF7, C3 = Purpose/genre/voice, Stage 3 (3rd–4th class)

Example: UFLI programme reference

Lesson 54: VCe a_e pattern ("cake", "gate", "same")
Cross-reference: Primary Language → Reading → TF4 (Phonics/word recognition) → Stage 2
Query: "UFLI Lesson 54, 2nd class" → matches programme_ref="UFLI/L54" + grade_band="1st-2nd"
Guard: generated plans must not use sounds from lessons > 54

Gap detection engine

Iterate all curriculum outcomes → query catalogue for each → any outcome with zero resources above confidence threshold is a gap → triggers Ops-Researcher to search curriculumonline.ie → if found, suggest to teacher → if not and teacher requests: Ops-Maker generates lesson plan. This is the core agent handoff chain that maps to 25% of the grade.

Design Journey Log — how we got here

Phase 1: Folder-Level Categorisation

First pass treated the teacher's own folder structure as the taxonomy. Result: 3–4 tags per file in 30 seconds. But missed format, grade band, pedagogy, source, licensing, and cross-cutting resources (a Christmas phonics worksheet in xmas/ not phonics/).

Phase 2: Content-Level Experiment

Tested 3 PDFs in fall resources literacy numeracy. Content extraction tripled tags (3 → 6–8 per file). Discovered two were identical duplicates. But 9 of 14 pages in one file yielded zero extractable text — the hard ceiling: image-heavy worksheets.

Phase 3: Quantifying Approaches

Benchmarked on 50 random PDFs. Full deep parse: ~90 min, ~$5 API. Optimised (gaps only): ~10–15 min, ~$0.55. 30% of PDFs image-heavy (<500 chars), 48% text-rich (>2,000 chars). The cost argument for sampling collapsed — $5 is trivially cheap.

Phase 4: Image-Heavy PDF Problem

Explored four solutions: Tesseract OCR (free, 14+ hours), Azure Document Intelligence (~$37), Marker (free, GPU-recommended, 14+ hours), Vision LLMs (Gemini Flash ~$2–12.50, captures pedagogical intent directly from the visual layout). Vision LLMs won on cost, speed, and quality of tag inference.

Phase 5: Reference Taxonomies

Discovered two-regime problem: modernised curriculum has outcome codes (TF, PC); 1999 curriculum doesn't. No public API from NCCA — taxonomies must be hand-authored. Jolly Phonics absent from collection despite being Ireland's dominant programme; UFLI is the teacher's chosen method (24 files).

Phase 6: Gap Filling Strategy

Evolved from "generate for every gap" → "search first, generate as fallback." Teacher keeps control of what enters their catalogue. curriculumonline.ie scraping tested and confirmed viable (91 outcome prose matches in raw HTML).

Phase 7: Architecture Decisions

Google Sheets → Excel Online (MS ecosystem). Client-side JSZip → Cloudflare Worker server-side (no exposed keys). MSAL.js auth → app-only Graph auth (no friction for demo, delegated auth as production fix). Pre-sync subset → all files bundleable (zero content limits).

Phase 8: Two Teams

Dev team builds once (Architect, Maker, Communicator, Manager). Ops team runs on query (Researcher, Designer, Maker, Communicator, Manager). Keelin shared as security/QA consultant. 11 agents across 6 role types prove the module's argument that agents are domain-specific, not generic.

Phase 9: UX & Interaction

Three entry points (Guided, Free-text, Browse) converging on one results+refinement panel. Disagreement as first-class interaction: thumbs down (session-level), "Not for this outcome" (catalogue improvement), "Generate something better" (Maker with negative example). Bundle always explicit and deliberate.

Phase 10: Tests Passed

curriculumonline.ie scraping: GO. Gemini Flash vision: GO (10/10 image-heavy PDFs correctly tagged, ~$2 for full parse). DeepSeek text classification: GO (~$3, ~90 min). All blocking unknowns resolved. Ready to build.
